# 云贵川风味家常菜藏书阁

家里的书都在这里：<https://zhuangxu0414-spec.github.io/yunguichuan-library/>

手机上打开就能用。可以搜书名、作者、出版社和简介里的词（繁体书名用简体也搜得到），按主题逛，按存放位置找；点开一本书能看到它放在哪儿，加进「想借的书」后一键复制清单发到群里。

## 家里添了新书，怎么更新

1. 在电脑上更新 `私家书藏-全部书籍.xlsx`（加一行，至少填「书名」和「书柜」）。
2. 打开这个仓库的网页，点 **Add file → Upload files**，把新的表格拖进去，文件名保持 `私家书藏-全部书籍.xlsx` 不变，点 **Commit changes**。
3. 等一两分钟，网页自动更新。进度可以在仓库的 **Actions** 页面看，绿色对勾就是好了。

## 主题标签是怎么来的

每本书的主题按下面的顺序决定，前面的优先：

1. 表格「标签」列里你自己填的。多个标签用逗号或顿号隔开，比如 `酷儿、文学`。
2. `scripts/tags.json` 里按 ISBN 记下的人工分类（现有的 438 本都在里面）。
3. 都没有的新书，按书名、作者和简介里的关键词自动猜。

想改某本书的分类，最简单的办法是在表格「标签」列里填上你想要的。网页上固定的十三个主题是：

酷儿、女性主义与性别、性与亲密、社会学与人类学、哲学与思想、历史与政治、劳动与经济、公益与行动、文学、漫画与艺术、心理与灵性、身体与健康、生活与工具书

填了这十三个以外的词也可以，它会作为一个新主题出现在网页上。

## 表格里会显示在网页上的列

书名、作者、出版社、书柜、标签、借给、阅读状态、备注、图书简介、作者简介。ISBN、价格这些不会显示在网页上（但表格本身放在这个公开仓库里，能被下载）。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `私家书藏-全部书籍.xlsx` | 书目表格，唯一需要日常维护的文件 |
| `public/index.html` | 网页本身 |
| `scripts/build_data.py` | 把表格转成网页数据 |
| `scripts/tags.json` | 人工主题分类 |
| `.github/workflows/deploy.yml` | 每次更新后自动发布 |
